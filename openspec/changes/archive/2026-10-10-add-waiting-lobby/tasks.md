# Tasks

Every behaviour is test-first (Red, then Green, then Refactor). Each test name states one behaviour. Commits follow
Conventional Commits and one type per commit: `feat` for production code, `test` for test-only commits, `docs` for the
ADR and guides. The change ships under `feat(race)`. The golden files are not regenerated by any task; a difference
there stops the work (see 0.2).
