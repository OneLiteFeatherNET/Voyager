Stufe 4 — `voyager-platform` + `voyager-server`: erster flugfähiger Build. Ausführliches Epic-Ziel siehe [anforderungen-voyager-rebuild.md](anforderungen-voyager-rebuild.md#4-ausbaustufen-uebersicht).

Hinweis: Ticket E4.9 (Configuration resolver) hat zwei klar unterscheidbare Nutzen für zwei
Rollen (Entwickler: testbarer, geschichteter Resolver; Betreiber: das operative
`-Dvoyager.config.check=true`-Kommando) und wurde daher in zwei User Stories aufgeteilt
(US-4.10 und US-4.11), beide mit Herkunft E4.9.
